# MCA Journey

An installable study, placement and discipline planner for an MCA student.
Works on a phone like an app, including offline.

**Live app:** https://lambent-stroopwafel-3ad631.netlify.app

## Features
- Daily planner with a morning "top 3" prompt, tasks, habit streaks and a study-time log
- Syllabus tracker for all four MCA semesters with module-level progress and elective selection
- Daily English practice (listening, speaking, vocabulary, writing) with levels and streaks
- Exam calendar that keeps the original and revised dates side by side
- Placement prep tracks for DSA and aptitude, plus UGC NET topics
- Marks and experience records, diary and notes, skill tracker
- History and progress charts, light and dark modes, six colour themes
- Backup and restore of all data as a file

## Built with
HTML, CSS and vanilla JavaScript. Data is stored in the browser (localStorage).
Installable as a Progressive Web App using a web app manifest and a service worker.

## Run it
Open `index.html` through any static host (Netlify, GitHub Pages). No build step.
